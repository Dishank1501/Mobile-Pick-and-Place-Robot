Mobile Pick and Place Robot
-  A high-power 4WD mobile robotic platform designed with a custom chassis for object pickup and precise placement at designated locations.
The system uses ESC-based motor control and a FlySky 2.4GHz RC transmitter–receiver system for smooth wireless maneuvering and real-time operation.

Project Overview
This robot is built for:
-  Object pickup and placement tasks
-  Industrial material handling concepts
-  Manual wireless control applications
-  Robotics prototyping & drivetrain testing
The platform combines high-torque Johnson motors, 30A ESCs, and servo-based steering/manipulation integrated through a FlySky RC system.

⚙️ Hardware Components
-  12V Battery
-  2 × 30A ESC (Electronic Speed Controllers)
-  4 × Johnson DC Motors (4WD configuration)
-  FlySky 2.4GHz Receiver
-  FlySky Transmitter
-  Servo Motors (Steering / Arm Control)
-  Custom Designed Chassis (STL files included
